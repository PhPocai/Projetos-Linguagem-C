# 💻 Projetos em Linguagem C

Repositório com exercícios e projetos práticos desenvolvidos durante minha graduação em Engenharia de Software, com foco em lógica de programação, estruturas de dados e algoritmos.

## 📚 Conteúdo

- **Fundamentos**: variáveis, estruturas condicionais, laços de repetição, funções, ponteiros e manipulação de vetores
- **Estruturas de Dados**: implementação de listas, pilhas, filas e outras estruturas clássicas
- **Algoritmos**: exercícios de lógica, ordenação, busca e resolução de problemas
- **Projetos práticos**: aplicações menores que consolidam os conceitos estudados

## 🎯 Objetivo

Evoluir habilidades em lógica de programação e desenvolvimento de sistemas, construindo uma base sólida em fundamentos de ciência da computação através da linguagem C.

## 🛠️ Tecnologias

- Linguagem C
- GCC

## 📂 Estrutura do repositório

```
Projetos-Linguagem-C/
├── fundamentos/          # Exercícios de base da linguagem
├── Estrutura de Dados/   # Implementações de estruturas de dados
└── projetos/             # Projetos práticos maiores
```

## 🚀 Como executar

```bash
gcc nome_do_arquivo.c -o programa
./programa
```
